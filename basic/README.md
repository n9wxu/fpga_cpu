# basic

BASIC interpreter written in C, compiled with the project's LLVM backend. It is developed in the simulator first.

Planned features:
- Line editor and plain-ASCII program files (SAVE/LOAD through the RP2350)
- Graphics: BACKDROP, BACKGROUND/SCROLL, SPRITE, WINDOW, VIEWPORT, PLOT/LINE/BOX/CIRCLE/FILL, PALETTE
- Sound: BEEP, SOUND, ENVELOPE, PLAY
- File I/O: OPEN/PRINT#/INPUT#/CLOSE
- PEEK/POKE access to GPIO, I2C and SPI
