Doom: pick it under Program. The first time, it downloads the game data (about 10 MB). Arrow keys move,
      Ctrl fires, Space opens doors, Shift runs, Alt strafes, 1–7 pick weapons, Esc is the menu, Enter selects. The
      CPU draws every frame itself at 50 MHz, so expect about 6 frames per second, as the simulator measures; a
      browser too slow for real time runs it slower still. This is
      doomgeneric (GPL v2, source in
      benchmarks/doom) with
      Freedoom: Phase 1 (BSD license)
      as its game data. It runs from 14 MB of simulator-only expansion RAM, more than the board has.
